Code Sample – Earnings Sensitivity Model


def earnings_sensitivity(base_nii, rate_shock_bps, beta=0.75):
    """
    Simple model to estimate the impact of an interest-rate shock
    on Net Interest Income (NII).

    Parameters
    ----------
    base_nii : float
        Current quarterly net interest income
    rate_shock_bps : float
        Parallel rate move in basis points (e.g., +100, -50)
    beta : float
        Balance sheet rate sensitivity (0 to 1)

    Returns
    -------
    float : projected NII after shock
    """
    shock_factor = 1 + (rate_shock_bps / 10000.0) * beta
    return base_nii * shock_factor

# Example:
projected = earnings_sensitivity(base_nii=1_000_000_000, rate_shock_bps=100)
print(f"Projected NII under +100 bps: ${projected:,.0f}")

Financial Metrics – Math Formulas

Net Present Value (NPV):

\[ \text{NPV} = \sum_{t=1}^{T} \frac{CF_t}{(1 + r)^t} - I_0 \]

Return on Equity (ROE):

\[ \text{ROE} = \frac{\text{Net Income}}{\text{Average Shareholders' Equity}} \]

Cost of Equity – CAPM:

\[ k_e = r_f + \beta (r_m - r_f) \]
