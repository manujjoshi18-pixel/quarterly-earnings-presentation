Return on Equity (ROE)

We monitor shareholder value using ROE:

\[ ROE = \frac{\text{Net Income}}{\text{Shareholders' Equity}} \]

Example: If net income is \$250M and equity is \$1B, then:

\[ ROE = \frac{250}{1000} = 0.25 = 25\% \]

Stress that sustained ROE above sector median is a key objective.
